# More Lore: Apple Pie

## Developer Notes
Most Fabric tools will NOT be used. Mojang has been updating their code so frequently that methods and other tools become useless. Mojang also has plans to make modifying the game easier (for both Mojang and mod developers). I've decided to wait until official methods are available. Despite the benefits that Data Generation provides, some of the most important things to this mod series is that updates can be developed quickly and that the code works similar to that of the base game.

External libraries will not be used, no matter how convenient that could make things. I do not want the mod to be dependent on someone else's update cycle. I have plans to maintain a lightweight library to maintain the mod series' independence. Hopefully Mojang will continue with their data driven updates to speed things up and provide some stability in their code structure.
